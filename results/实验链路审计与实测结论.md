## 二、口径修正后的实测结果

### 2.1 结构路由的判别力受"结构覆盖率"硬约束

"结构覆盖率" = 结构画像非零的左侧实体占比 = **与至少一个训练种子相邻**的实体比例。  
覆盖不到的查询，结构路由**必然失分**，这是它的绝对上界。

| 数据集                | 结构覆盖率 | 测试查询画像全零 | 结构路由单独 | 字面名通道      | 属性通道       | 融合最好       | 纯语义基线  |
| ------------------ | ----- | -------- | ------ | ---------- | ---------- | ---------- | ------ |
| DBP15K fr_en       | 45.3% | 16.3%    | 0.2660 | 0.7800     | 0.5900     | **0.9190** | 0.8680 |
| DBP15K zh_en       | 42.6% | 29.0%    | 0.2390 | **0.0270** | 0.4370     | **0.5840** | 0.4370 |
| WN18（自对齐压力测试，名称屏蔽） | 50.8% | 45.5%    | 0.1920 | **0.0000** | **0.0040** | **0.2450** | 0.0040 |
| FB15k-237（同上）      | 92.5% | 7.2%     | 0.0340 | 0.0000     | 0.0210     | 0.0600     | 0.0210 |

> "纯语义基线"＝融合权重取 0（即完全不用结构路由）时的同一融合得分，**不是**单通道的值。

**结构路由的净贡献**：fr_en **+0.051**、zh_en **+0.146**、WN18 **+0.238**。  
在 zh_en 与 WN18 上，字面名通道（跨语言/名称屏蔽）几乎无信息，结构路由是**唯一可迁移的信号**。

**一处需要如实说明的负面结果**：FB15k-237 上结构覆盖率高达 92.5%，但结构路由单独只有 0.0340。  
原因是该压力测试把**同一张图的边随机二分**，这恰好破坏了结构匹配赖以成立的前提  
（两侧邻域同构）。该测试实际度量的是**边稀疏鲁棒性**，不是跨图结构同构，  
故不能作为结构路由的代表性证据，正文需按此定位。

### 2.2 结构路由的增益不是"并列救援"

曾怀疑增益来自"语义路由整行常数 → 只能取下标 0 → 加任意非零权重的结构路由都能救活"。  
实测：**退化行 = 0/1000**，该假设不成立，增益是真实结构信号。

### 2.3 三个范畴通道：纤维/类型有效，粘合无效

在同一基线上扫描（fr_en 基线 0.9190、zh_en 基线 0.5830、WN18 基线 0.2430）：

| 数据集   | 纤维罚最好   | 类型先验最好  | 粘合通道最好      | 三者联合最好  |
| ----- | ------- | ------- | ----------- | ------- |
| fr_en | +0.0020 | 0.0000  | **−0.006**  | +0.0020 |
| zh_en | +0.0050 | +0.0060 | **−0.025**  | +0.0060 |
| WN18  | −0.0030 | −0.0010 | **−0.0030** | 0.0000  |

**若只看 Hits@1，三个通道都接近零增益。但这是错误的口径**：纤维保持是**硬约束**，  
它的产出是"约束被真正落实"，而不是精度。把硬约束塞进精度目标里，它一旦净亏就会被关掉，  
论文承诺的约束便形同虚设。正确的验收是 **(精度, 约束落实率) 权衡前沿**：

**DBP15K fr_en**（纤维保持率基线 0.5260）

| 纤维罚 β | Hits@1            | 纤维保持率          |
| ----- | ----------------- | -------------- |
| 0.00  | 0.9190            | 0.5260         |
| 0.25  | 0.9190（**零精度代价**） | 0.5350（+0.9 点） |
| 0.50  | 0.9190（**零精度代价**） | 0.5430（+1.7 点） |
| 1.00  | 0.9120（−0.007）    | 0.5560（+3.0 点） |

**DBP15K zh_en**（基线 0.4420）—— 前两行是**严格 Pareto 改善**

| β        | 类型先验 γ   | Hits@1             | 纤维保持率              |
| -------- | -------- | ------------------ | ------------------ |
| 0.00     | 0.00     | 0.5830             | 0.4420             |
| **0.10** | **0.15** | **0.5890（+0.006）** | **0.4910（+4.9 点）** |
| **0.10** | **0.40** | **0.5890（+0.006）** | **0.5130（+7.1 点）** |
| 0.25     | 0.15     | 0.5850（+0.002）     | 0.5400（+9.8 点）     |
| 1.00     | 0.15     | 0.5470（−0.036）     | 0.6710（+22.9 点）    |

**结论**：纤维罚与类型先验**在不牺牲精度的区间内可用，甚至同时提升精度**（zh_en 上  
把约束落实率从 0.442 提到 0.49–0.51，精度还涨 0.6 点）。**粘合通道在全部四个数据集上  
都是负贡献**，是本轮唯一站不住的部件。

### 2.4 一个必须如实披露的数据性质

DBP15K fr_en 的测试对中，**48.93% 两侧表层名完全相同**。表层名相似度方法在该子集上  
命中率 **1.0000**、在异名子集上 0.5261 —— 即其整体成绩**主要来自"同名白拿"**。  
正文与表格需同时给出同名/异名两个子集的分解，否则会被质疑。

另外，逐层排查确认：三个划分（种子/验证/测试）**两两不相交**（交集 0 对），  
测试对的左侧与右侧下标均唯一（1 对 1），语义视图的构造**从不读取对齐真值文件**——  
数据链路上不存在泄漏通道。

## 三、对第 5 章叙述的影响（建议）

1. **主表取"精度优先"**：调参准则仍是"附加通道须以 2 个标准误的显著增益换取启用"，  
   从而保证本文方法在关闭全部附加通道时**与两视图线性融合的对照逐位相同**，  
   附加通道只可能加分。这保住了"不靠调参占便宜"的可信度。
2. **4.2（纤维约束）的验收口径改为"约束落实率"**，并给出上述 (精度, 约束落实率) 前沿。  
   不要再用 Hits@1 论证硬约束的价值 —— 理论上也说不通。
3. **4.4（粘合通道）需改为负面结论 + 归因**：本轮全部数据集上均为负贡献。  
   可报的正面内容有两条：① 纤维掩码在传输**之前**施加这一实现选择是可核算的；  
   ② 该通道的偏离分量（Δ_glue）本身是 SPS 的有效构成，且其"尺度安全化"是必要的实现约束。  
   若要保留它在精度上的作用，需要重新设计（候选短名单与传输代价的构造是关键）。
4. **结构路由的定位要写清**：它是本文真实的精度来源（+0.05 ~ +0.24），  
   但受**结构覆盖率**硬约束，覆盖率由"种子密度 × 顶点度"决定；  
   跨语言字面名越不可用，它的相对价值越大。
5. **自对齐压力测试（FB15k-237/WN18）的定位**：边随机二分破坏两侧同构，  
   它测的是边稀疏鲁棒性，不能当作跨图同构任务的代表。
