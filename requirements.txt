# Track A′（跨模态编码器）额外依赖 —— 只在跑 `--mm-encoder` 时需要
#
# **torchvision 不要写在这里、更不要 `pip install torchvision` 随手装。**
# 它的 wheel METADATA 写死 `Requires-Dist: torch (==X.Y.Z)`，版本错配会直接
# 换掉 torch（CUDA 版 → 可能被降级/换成 CPU 版），属于最坏的一类错误。
# 2026-09-28 实测：torch 2.14.0+cu126 ⇔ torchvision 0.29.0+cu126（METADATA 实证）。
#
# 依赖关系（实测踩坑记录）：
#   * `transformers.AutoImageProcessor` **依赖 torchvision** —— 只装 transformers 会在
#     编码器第一步就 `ImportError: requires the Torchvision library`（本轮真实发生过）。
#   * `pillow` 是 torchvision 与图像裁剪（`ImageBank` 直接随机读 flickr30k-images.zip）的前提。
#
# 正确装法（按 torch 版本精确配对）：取**定版** cu126 wheel，
# 用 `--no-deps --no-index` 安装，保证不动 torch。
